# ============================================================================
# Hand-written mail metadata fixtures for the offline archiving harness.
#
# Every `mail=` line stands for one unread message that a real run would have
# received through ForEachEmailX.  Only the metadata the workflow actually
# touches is modelled: sender address, subject, Date header and whether any
# attachment exists.
#
# Format
#   [scenario-key]                scenario identifier
#   description=...               human readable note
#   success=N                     number of emails expected to be archived
#   failure=N                     number of emails expected to be listed as failed
#   template=success|failure      report template expected to be used
#   mail=sender|subject|date|attachments|failAt
#       sender       From address, or <empty> for a missing address
#       subject      Subject text, or <empty> for an empty subject
#       date         raw Date header value, or <empty> for a missing header
#       attachments  yes | no
#       failAt       -                      behaves normally
#                    subject-read           reading .Subject throws
#                    date-parse             the Date header cannot be parsed
#                    save-mail              SaveMailX throws
#                    save-attachments       SaveMailAttachmentsX throws
#                    sender-read            reading .From throws (non fatal)
#
# The failAt values are injected at exactly the step named, so a failure is
# reproducible without a mail server.
# ============================================================================
