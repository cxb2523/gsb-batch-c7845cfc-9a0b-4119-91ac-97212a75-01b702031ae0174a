# Shopee 選品採集工具 - Chrome 擴充功能

## 📁 檔案結構

```
shopee-collector/
├── manifest.json          # 擴充功能設定
├── market.js              # 市場／幣種／數字慣例（content.js 與 popup 共用）
├── content.js             # 注入 Shopee 頁面的採集腳本
├── background.js          # 背景 Service Worker（派發任務、開 Tab）
├── relay.js               # localhost:8002 保活中繼
├── icons/
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── popup/
    ├── popup.html         # 彈出視窗介面
    └── popup.js           # 彈出視窗邏輯
```

> `market.js` 必須在 `content.js` / `popup.js` 之前載入（manifest 與 popup.html 已按此順序配置）。

---

## 🚀 安裝步驟（開發者模式）

1. 打開 Chrome 瀏覽器
2. 網址列輸入：`chrome://extensions`
3. 開啟右上角「**開發人員模式**」
4. 點擊「**載入未封裝項目**」
5. 選擇本資料夾（`shopee-collector`）
6. 工具列出現 🛍 圖示即安裝成功

---

## 📖 使用方式

### 第一步：前往 Shopee 搜索頁
- 打開 https://shopee.tw
- 搜索目標品類，例如：`收納盒`、`掛鉤`、`理線夾`
- 等待商品列表完整載入（往下滾動讓懶載入圖片出現）

### 第二步：執行採集
- 點擊工具列的 🛍 圖示開啟工具
- 確認狀態顯示「已就緒」（綠點）
- 點擊「**開始採集本頁商品**」

### 第三步：查看結果
- 自動跳轉到「結果」頁
- 每件商品會顯示：
  - 售價、銷量、評分
  - **選品評分（0-100分）**
  - 評級：強烈推薦 / 可以測款 / 謹慎考慮 / 直接放棄
  - 點擊 ▾ 展開改善備註

### 第四步：收藏與匯出
- 點擊 ☆ 收藏潛力品（存在「已存」頁）
- 點擊「⬇ 匯出 CSV」下載完整數據到 Excel 分析

## 🎯 評分邏輯（實際滿分 90）

| 維度 | 實際滿分 | 評估方式 |
|------|:--------:|----------|
| 銷量表現 | 15分 | 銷量 ≥1000 滿分，越少扣越多 |
| 評分信任度 | 15分 | 評分 ≥4.7 且評論 ≥50 滿分 |
| 規格/組合 | 10分 | 商品名含「組合/套裝/多入」加分 |
| 非紅海定價 | 15分 | 最佳價格區間，依市場取 `market.js` 的 `priceTiers`（台灣站預設 NT$150–499） |
| 圖片可執行性 | 10分 | 固定基準分，需人工確認 |
| 不易碎/售後少 | 9分 | 名稱含玻璃/電器等扣分 |
| 體積/包裝 | 8分 | 固定基準分 |
| 法規風險 | 8分 | 名稱含認證/食品等扣分 |
| **合計** | **90分** | 理論區間 30–90 |

> ⚠️ 此表的實際滿分是 90（非 100）。售價分段依市場讀取，與後端
> `markets.py` 的 `price_tiers` 對齊。解析不到價格或銷量時，該維度不計分
> 並在備註中標明「價格缺失 / 銷量缺失」，因此這類商品的總分可能偏低。

**判斷標準：**
- 🟢 80+ 強烈推薦：優先測款
- 🟢 70-79 可以測款：值得小量備貨
- 🟡 60-69 謹慎考慮：需人工再評估
- 🔴 <60 直接放棄：跳過此商品

## ⚠️ 注意事項

1. **僅讀取頁面 DOM**：本工具只讀取你瀏覽器已載入的頁面內容，不對 Shopee 發送額外請求
2. **自動模式無需手動滾動**：自動採集會分段滾動載入；手動模式請先滾動頁面確保商品載入完成
3. **結果僅供參考**：評分為輔助決策工具，最終選品仍需結合個人判斷
4. **數據僅存本機**：採集結果存在本機 `chrome.storage`；若使用「☁ 同步到後端」，數據會發送到**你自己機器上的** `http://localhost:8000`，不經過任何外部伺服器
5. **市場傳遞**：任務派發端（`background.js`）會按任務 `market` 打開對應域名，並把 `market` 寫進地址 hash（`#selekt-task-{id}&market={code}`）。頁面端（`content.js`）優先採用傳入市場 → 缺失時按域名推斷 → 最後回退台灣站。手動採集按當前域名判斷市場，8 個站點皆支援。
6. **價格按市場幣種解析**：`market.js` 識別 Rp / ฿ / ₫ / RM / ₱ / $ / NT$ / S$ / R$，並處理印尼、越南、巴西的「.」千位、「,」小數慣例。**解析不到價格的商品會標記 `missing: ["price"]`，價格為 `null` 而非 0**；頁面完全沒有商品卡片時回傳 `error`，任務結算為失敗。

## 🔧 常見問題

**Q：點擊採集後顯示「採集失敗」？**
A：重新整理 Shopee 頁面，等完整載入後再試

**Q：採集到 0 件商品？**
A：Shopee 可能更新了頁面結構，請回報問題。注意：若頁面完全沒有商品卡片，擴充會回傳 `no_cards_found`，後端任務會標記為 `failed`（不再顯示為「成功 0 件」）。

**Q：為什麼某件商品顯示「價格缺失」？**
A：該卡片內找不到對應市場幣種的價格文字（常見於廣告位、優惠角標卡）。這是如實的字段缺失標記，不是抓到 0 元；匯出 CSV 時該欄留空。

**Q：評分和我的判斷不符？**
A：正常！評分基於可讀取的公開數據，圖片品質、痛點清晰度等需人工判斷

**Q：CSV 匯出後 Excel 亂碼？**
A：開啟 Excel → 資料 → 從文字/CSV → 選擇 UTF-8 編碼
